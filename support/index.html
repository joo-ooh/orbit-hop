자주 묻는 질문

최고 기록이 사라졌어요.
기록은 휴대폰 안에만 저장돼요. 앱을 삭제하면 기록도 함께 지워지고, 다른 기기로 옮겨지지 않아요. iPhone에서 Game Center에 로그인되어 있었다면 랭킹에 올라간 최고 점수는 Game Center에서 볼 수 있어요.

소리가 나지 않아요.
iPhone 옆면의 무음 스위치가 켜져 있으면 소리가 나지 않아요. 게임 화면 오른쪽 위의 소리 버튼도 확인해 주세요.

진동이 오지 않아요.
게임 화면 오른쪽 위의 진동 버튼이 "진동 끔"으로 되어 있지 않은지 확인해 주세요. 휴대폰 설정에서 시스템 햅틱이 꺼져 있어도 진동이 오지 않아요.

랭킹 버튼이 보이지 않아요.
랭킹은 iPhone의 Game Center를 사용해요. iPhone 설정 > Game Center에 로그인하면 메뉴에 랭킹 버튼이 나타나요. Android에서는 아직 랭킹을 지원하지 않아요.
